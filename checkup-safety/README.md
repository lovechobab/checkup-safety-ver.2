# 검진 안전 알리미 (교육용 프로토타입)

일반 국가건강검진 현장에서 **문진 + 당일 측정값 + (있으면) 과거 기록**을 조합해, 검사 중 위험이 커지는 수검자를 찾아
해당 검사실에 경고·조치·근거를 띄우고, 수검자별 **검사 순서**를 추천하는 프로그램입니다.

> ⚠ 교육용 프로토타입입니다. 실제 진단·치료·처방 결정에 쓰지 마세요. 모든 수검자 데이터는 가상(합성) 데이터입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py          # 브라우저에서 http://localhost:8501
pytest -q                     # 테스트 41개
```

- API 키, 유료 서비스, 인터넷 연결이 필요 없습니다.
- **빠른 시연:** 왼쪽 [시연 시나리오 9건 한꺼번에 등록] 버튼
- **실시간 시연:** 브라우저 탭 2개 — 한쪽은 [실시간 대시보드], 다른 쪽에서 [② 신체계측·혈압] 입력 → 3초 안에 반영

## 검사 범위

| 범위 | 검사 | 비고 |
|---|---|---|
| 일반 국가건강검진 (기본) | 신체계측·혈압, 시력·청력, 채혈, 소변검사, 흉부 X-ray, 구강검진 | 경희의료원 일반검진 항목 기준 |
| 종합검진 확장 모듈 (선택) | 조영 CT, MRI, 수면 위·대장내시경, 운동부하, 폐기능 | 사이드바 토글로 켜고 끔 |

## 화면

| 화면 | 내용 |
|---|---|
| 실시간 대시보드 | 대기 중 수검자 전체의 경고를 검사실별로 표시, 추천 검사 순서 |
| ① 접수·문진 | 공복 시간·임신·생리 + 추가 문진. 과거 기록(Synthea 합성 환자) 불러오기 가능 |
| ② 신체계측·혈압 | 키·몸무게·허리둘레·혈압·맥박(필요 시 체온·SpO₂·현장 혈당) |
| ③ 검사실 화면 | 검사실별 경고, 이유, 조치, 참고문헌, 조치 확인 기록 |
| 규칙과 근거 | 규칙 39개(일반검진 22개 + 확장 17개)와 근거 수준·참고문헌 |
| 한국인 합성 코호트 | 국민건강통계 2024로 만든 가상 수검자에서 경고 빈도·부담 추정, 가정값 민감도 분석 |
| 증례 검증 | 가상 증례 30건에 대한 평가자 판단 vs 프로그램 비교(민감도·특이도·kappa) |

## 일반검진 핵심 규칙

| 모듈 | 예시 |
|---|---|
| 채혈 실신 | 과거 채혈 실신 + (SBP<100, BMI<18.5, 탈수, 금식 ≥12h) → 누워서 채혈, 10분 관찰 |
| 채혈 출혈 | 항응고제·항혈소판제 → 충분히 압박 / 항응고제 + 구강검진 → 치과의사 공유 |
| 금식 저혈당 | 당뇨 + 인슐린/설포닐우레아 → 접수 즉시 혈당, **채혈을 먼저** 하고 바로 식사 |
| 임신 | 가임기 여성 + 임신 여부 모름 → 흉부 X-ray 전 확인, **촬영은 마지막에** |
| 검사 품질 | 공복 8시간 미만 → 공복혈당·지질 해석 주의 / 생리 중 → 소변 잠혈·단백 위양성 |
| 혈압 | ≥180/110 → 재측정 후 의사 보고 |
| 낙상·의사소통 | 65세 이상 + 낙상력/보행보조기구 → 동행·보조 / 인지장애·청력 저하 → 보호자, 글 안내 |

## 데이터

- `data/knhanes/` — 질병관리청 **국민건강통계 2024** 표(비만·고혈압·당뇨병·빈혈·만성콩팥병·의사진단경험).
  성·연령별 BMI·혈압·혈색소 백분위수와 유병률을 `knhanes.py`가 읽습니다.
- `data/assumptions.yaml` — 통계표에 없는 항목의 **가정값**(채혈 실신 경험률, 생리 중 비율 등). 확인되면 값과 출처를 바꾸세요.
- `data/synthea/` — Synthea 합성 환자 86명(과거 기록 불러오기 시연용).
- `validation/vignettes.yaml` — 검증용 가상 증례 30건.

## 증례 검증 절차 (보고서 '검증' 장)

```bash
python vignette_validation.py template   # validation/평가지.xlsx 생성
# 평가자 2명이 '평가자A', '평가자B' 시트를 각자 채움 (프로그램 결과를 보지 않고)
# 다른 칸은 토의·교수님 확인으로 '합의정답' 시트 작성
python vignette_validation.py score validation/평가지.xlsx
```

앱의 [증례 검증] 화면에 파일을 올려도 같은 결과가 나옵니다.

## 구조

```
app.py                  Streamlit 화면
engine.py               규칙 평가, BMI·STOP-Bang 계산, 검사 순서 추천
rules.yaml              규칙 39개 + 참고문헌 (기준값은 여기만 고치면 됨)

tests/test_engine.py    규칙·경계값·결측·검사 순서·검증 도구 테스트
```

## 알려진 한계

- 기준값은 학생 팀이 문헌을 정리한 것으로, 전문가 검증 전입니다. 근거 수준이 '팀 설정'인 규칙은 지도교수 검토가 필요합니다.
- 실제 사건(실신·저혈당 발생) 자료가 없어 실제 예측 정확도는 측정할 수 없습니다. 검증은 증례 평가와 합성 코호트 분석까지입니다.
- 합성 코호트는 통계표의 변수별 분포만 재현하며, 변수 간 상관과 일부 항목은 가정값에 의존합니다.
- 채혈 결과(혈색소·크레아티닌)는 당일에 나오지 않으므로, 실시간 경고에는 과거 기록 값만 쓸 수 있습니다.
- 저장소는 서버 메모리입니다(DB 없음). 서버를 다시 켜면 대기열이 사라집니다.
